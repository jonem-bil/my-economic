# My Economic（我的经济）

一个**纯本地**的个人记账程序。数据只存在你自己的电脑上，不联网、不上传、没有账号。

双击 `开始使用.cmd` 就能跑，**不需要安装 Python**（运行时已经打包在 `python\` 文件夹里）。

---

## 它解决什么问题

市面上的记账 App 大多要注册账号、把账单传到云端，而且分类是"系统推荐的"，你想看的角度（比如"我在某个场景下花了多少"）根本表达不出来。

这个程序的思路不一样：

- **数据不出本机** —— 账本就是 `data\bookkeeping.db` 一个文件，拷走就是全部
- **分类自己定** —— 两级分类树（大分类 → 小分类）完全由你维护，没有"智能推荐"
- **先确认再算数** —— 导入的账单先进「待确认」，你确认后分类才算数，统计才是可信的
- **能对上银行** —— 账户余额可以和手机银行 App 上的数字精确对上（见下面「账户对账」）

## 主要功能

### 总览
- 收入 / 支出 / 结余 / 待确认四项关键数字
- 收支趋势图，**柱状图与折线图可切换**（默认柱状）
- 收入、支出分类占比饼图
- 时间范围：全部 / 按年 / 按月 / 按季 / 按周 / 按日

### 账单（三个视角）
| 视角 | 用来干什么 |
|---|---|
| **条目统计** | 原始账目表格。表头就能筛选：时间、类型、分类、账户、金额区间；支持搜索、编辑、删除、改分类 |
| **按分类查找** | 从大分类往下钻进小分类，看每一类下有哪些账目 |
| **交互消费统计** | 按"交易对象"聚合。看你和某个商家/平台一共来往多少钱，可展开到小分类，可按时间/笔数/金额筛选 |

### 名单机制
把某些交易对象或单条账目放进「名单」，用来看得更清楚：

- 白名单、大额名单是默认的两个
- 可以自己新建名单、改名、删除、复制
- 名单可以**置顶到三个快捷位**（在交互消费统计顶部一键切换）
- 用途是"折叠/排除"：比如把不关心的对象隐藏掉，只看关心的

### 待确认
导入的账目先落在这里，等你说"这条是餐饮"才算数。

- 逐条确认，或**按交易对象批量确认**（淘宝 75 笔一次归完）
- 确认错了可以撤销
- 支持关键词规则自动归类（打开后，已知对象的账目会自动填好分类）

### 待质量审核
本地扫描账本里的可疑数据，**不消耗任何 token、不联网**，四类问题：

1. **内部划转被当收支** —— 自己账户间搬钱却记成了收入/支出
2. **疑似重复** —— 同一笔被记了两次
3. **孤儿分类** —— 账目引用的分类已经不存在
4. **异常大额** —— 单笔金额显著高于同类

### 账户对账
每个账户能看到「余额」，并显示它是怎么算出来的（期初多少 + 流水多少）。

- **期初余额**可编辑
- **倒推**：输入手机银行 App 上看到的真实余额，自动算出该填多少期初
- **定位期初**：把该账户所有大额流入列出来，你勾选哪些其实是"本金注入"，标记后不计入收入

### 导入账单
设置页里点「导入」即可，支持四种格式：

- 支付宝交易明细 CSV
- 微信支付账单 XLSX
- 招商银行交易流水 PDF（电子版）
- 邮政银行历史明细 PDF（电子版）

流程是：**选目录 → 预览（告诉你会导入多少条、哪些跳过）→ 确认导入**。

导入时按「支付方式」判定归属：用零钱付的记微信账户，用银行卡付的记银行账户，**同一笔钱不会记两次**。

## 数据在哪

| 内容 | 位置 |
|---|---|
| 账本数据库 | `data\bookkeeping.db` |
| 分类配置 | `data\config.yaml` |
| 自动备份 | `backup\`（每次启动自动备份，保留最近 30 份） |

**换电脑时，把 `data\` 文件夹一起拷走就是全部数据。**

## 常见问题

**双击后黑窗口一闪就没**
`python\` 文件夹可能被杀毒软件删了，检查一下它还在不在。

**浏览器没自动打开**
手动访问 <http://127.0.0.1:8765>

**提示端口被占用**
说明已经有一份在运行，关掉旧窗口再开。

**账本数据会不会被传到网上**
不会。整个程序不发起任何外部网络请求，只有本机 127.0.0.1 的内部通信。

## 未来想做的

记账这件事真正难的从来不是"记下来"，而是**"我想看的角度说不出来"**。

现在能做到"按分类看"、"按对象看"、"按时间看"，但真正想要的是——

> **给一套筛选条件起个名字，叫它「场景A」「场景B」，一键切换，各自看各自的账。**

再往后：

- **多系统对比**：两个生活场景，同一段时间花销结构差多少
- **辅助识别**：转账、重复、本金注入自动标出来，人只做判断不做苦力
- **完全脱离 AI**：所有判断规则都沉淀在程序里，不需要每次找人帮忙

目标不是功能越来越多，而是**你自己能配出一套适合自己的系统**。
